Conectar la bolsa real

El modo Bolsa real usa Finnhub, un servicio gratuito de datos de mercado. Necesitas tu propia clave (API key):

  1. Entra a finnhub.io/register y crea una cuenta gratis.
  2. En el Dashboard, copia tu API key.
  3. Pégala aquí abajo y pulsa Guardar las claves.

La clave se guarda solo en este navegador. La página publicada en claude.ai bloquea las conexiones a la bolsa: para el modo real, abre el archivo HTML en tu navegador o súbelo a GitHub Pages.

Cómo leer una vela

Una vela resume un periodo (aquí, un día) con cuatro precios: apertura, cierre, máximo y mínimo.

Verde: cerró más alto de lo que abrió. Roja: cerró más bajo.

El cuerpo muestra el cambio entre apertura y cierre. Las mechas muestran hasta dónde llegó el precio. Una mecha larga indica que compradores y vendedores pelearon fuerte.
